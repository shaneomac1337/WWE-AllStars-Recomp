# WWE All Stars Recomp 1.5.0

**You need your own copy of the game: a disc image of WWE All Stars (Xbox 360,
USA/Europe) and its Title Update 2, both dumped from your own console. This download
contains no game files, no update and no DLC.**

## What's new

- **Smoother online matches.** The game's own netcode rounds its step rate down, so an
  online match ran at 29 steps a second instead of 30. That is slightly slower than the
  display, and the same frame showed twice about once a second. Online matches now step
  at a true 30 and run at 60 ticks a second, like offline matches. A match also starts at
  full rate; before, its first seconds ran slow. There is no setting: both players always
  get it.
- **The network thread stops keeping a CPU core busy.** In online play it spun one core
  for the whole session. It now waits until a packet arrives or you press a button, and
  your input goes out at once. On a 4-core PC or a Steam Deck the game gets that core
  back.
- **Package mods for DLC wrestlers work.** A mod that replaces a file an installed DLC
  pack also has, such as Cody Rhodes' attire `CHR_219_A.xxx`, had no effect, because the
  game reads a DLC wrestler's files from the DLC first. The launcher now puts that file
  into the DLC it builds for mods, so the mod's copy wins. Such a mod is offline only,
  like a mod that adds wrestlers, and the MODS page says so. Package names only a DLC
  pack has, such as `CHR_116_A.xxx`, now install once that pack is installed. Thanks to
  the modder on Reddit who reported it with their file.
- **A possible fix for Intel GPUs on Native**
  ([#3](https://github.com/shaneomac1337/WWE-AllStars-Recomp/issues/3)). Vulkan's
  validation layer showed an error from the first frames on our AMD card: a few 2D draws,
  such as the splash screen, gave the GPU less vertex data than their layout reads. AMD
  shrugs it off; Intel may not. It is fixed now, but we have no Intel machine, so we
  don't know yet whether this is what crashes Iris Xe at start. If you have an Intel GPU,
  please try Native and tell us on #3, with the crash report if it still fails.

## Update

Extract the zip over your existing folder, or let the launcher's update check take you
to this page. Your settings, saves, mods and game files stay where they are.

## Known limits

- Online play pairs only players on the same release: update together with your
  friends. 1.4.0 and 1.5.0 don't see each other's lobbies.
- Mods are experimental. The format may still change.
- Ranked Match doesn't work yet; Player Match does.
- The in-game store button does nothing; add DLC from the launcher.
- A crash that Windows stops at once (a "fast fail") still ends without a crash report;
  then attach the session log from **Open logs**.
- Tested on Windows 11 with an RX 7900 XT, and on a Steam Deck (SteamOS through Proton).
  If Native still fails on your Intel GPU, Emulated is the way to play there for now.
