# WWE All Stars Recomp 1.3.0

**You need your own copy of the game: a disc image of WWE All Stars (Xbox 360,
USA/Europe) and its Title Update 2, both dumped from your own console. This download
contains no game files, no update and no DLC.**

## What's new

- **When the GPU stops working, the game says so**
  ([#3](https://github.com/shaneomac1337/WWE-AllStars-Recomp/issues/3)). If the GPU or
  driver fails under the Native renderer, the game now ends the session at once instead of
  carrying on broken and crashing later. The launcher tells you the GPU stopped working on
  Native and offers **SWITCH TO EMULATED**, which plays on the Emulated renderer and
  remembers the choice. Native stays the default.
- **Crash reports.** A crash of the game or the launcher, or a GPU failure, saves one zip
  (`logs\crash-<date and time>.zip`) with the session log, the launcher log, your
  settings, a small dump and the version, renderer, GPU and driver. The game tells you where it is, the launcher's
  **OPEN CRASH REPORT** button opens it, and the launcher lists reports you haven't seen at
  its next start. It holds no game data and is never uploaded: attach it to your bug
  report. The launcher keeps the last 10.
- **Reduce effects** (Settings > LAUNCHER, or start the launcher with
  `--reduce-effects`). Turns off the launcher's see-through backdrop and its animations,
  for weak laptops, and to test the launcher freeze in
  [#1](https://github.com/shaneomac1337/WWE-AllStars-Recomp/issues/1). The launcher now
  writes each step around picking a file to `logs\launcher.log`, so a frozen run shows
  where it stopped.
- **EXIT TO DESKTOP** in the game's main menu, with a confirm. It closes the game the same
  way the window's close button does.
- **Starting without the launcher** was already possible and is now in the README: after
  the first setup, `game\wweallstars.exe` starts on its own, from a shortcut or from Steam
  Game Mode.

## Update

Extract the zip over your existing folder, or let the launcher's update check take you
to this page. Your settings, saves and game files stay where they are.

## Known limits

- Online play pairs only players on the same release: update together with your
  friends.
- Ranked Match doesn't work yet; Player Match does.
- The in-game store button does nothing; add DLC from the launcher.
- A crash that Windows stops at once (a "fast fail") still ends without a crash report;
  then attach the session log from **Open logs**.
- Tested on Windows 11 with an RX 7900 XT, and on a Steam Deck (SteamOS through Proton).
  Intel GPUs fail on Native for some players; Emulated is the way to play there for now.
  A bug report with the crash report helps.
