# WWE All Stars Recomp 2.0.0

**You need your own copy of the game: a disc image of WWE All Stars (Xbox 360,
USA/Europe) and its Title Update 2, both dumped from your own console. This download
contains no game files, no update and no DLC.**

## What's new

- **120 fps matches are no longer experimental.** Lifts, climbs, springboards, ring exits and
  re-entries used to make wrestlers drop or jump for a frame, because those moves were written
  for 60 steps a second. They now move as smoothly as the rest of the match. Turning and walking
  no longer look too snappy, and the HUD's meters pulse at their normal speed. The option is still
  off by default, because it needs a strong GPU, and online matches still run at 60.
- **Cheats.** Five new rows on the GAMEPLAY tab, all off by default, which also work during a match
  from the in-game page (F4): infinite finishers, infinite signatures, max health, weak enemy
  (CPU opponents lose health three times as fast) and no reversal (CPU opponents can't reverse
  your moves). They do nothing online. Wins with a cheat on still count towards progress and
  achievements.
- **No more virus warning from the shader converter.** Windows Defender started removing
  `XenosRecomp.exe` as `Trojan:Win32/Bearfoos.B!ml`, and without it the shader step fails. That was
  a false alarm from its machine-learning model. The release no longer has that file: the game exe
  now converts the shaders itself, with the same result, and the launcher deletes the old file from
  your folder. This build was clean on Windows Defender and on VirusTotal when we released it.
- **Created superstars no longer freeze the select screen.** About 1 name in 16 made a
  superstar the game could not load, and the select screen froze as soon as the cursor
  reached it. The game wrote that superstar's save under one file name and looked for it
  under another. Superstars you already made with such a name start working, and their
  saves are unchanged. The same code is in the Xbox 360 game.
- **A likely fix for the crash when leaving Create A Superstar** (GitHub #16). When the loader
  screen failed to open, the game crashed. It now tries again once. We forced that failure to test
  this, but we could not reproduce the original crash on our PC, so please tell us if it still
  happens.
- **Fill screen (crop edges).** A new setting on the DISPLAY tab, off by default. It crops up to
  5% of the picture from each side instead of showing black bars. This fills a 16:10 screen;
  wider or squarer screens keep smaller bars. Parts of the HUD can sit close to the edge. A 16:9
  screen shows no change. This is a crop, not real widescreen.
- **Mods can move a package to another slot.** A mod file saved under the name of another slot
  used to hang the game, so the launcher refused it. When the old and new names are the same
  length, such as `Arena_005_Cin_Entrance.xxx` saved as `Arena_003_Cin_Entrance.xxx`, the launcher
  now accepts it, notes the rename on the Mods tab and writes a renamed copy at Play. Other
  renames are still refused, with the reason why.
- **A possible fix for the Intel crash on the Native renderer.** Every draw that uses a
  texture still loading read a GPU descriptor the game had never filled in. That is fixed, and
  Vulkan's GPU validation no longer reports it. We could not confirm this cures the crash:
  the one Intel PC we tested (HD Graphics 520) did not crash on 1.7.0 either. If the game
  still crashes on Intel, please send the crash report from `logs\`.

## Update

Extract the zip over your existing folder, or let the launcher's update check take you
to this page. Your settings, saves, mods and game files stay where they are.

## Known limits

- Online play pairs only players on the same release: update together with your
  friends. We did not retest a match across two home networks for this release.
- At 120 fps a few moves can still show a small body jump for one frame, mostly on landings.
- Mods are experimental. The format may still change.
- Ranked Match doesn't work yet; Player Match does.
- The in-game store button does nothing; add DLC from the launcher.
- Emulated stays too slow on integrated GPUs.
- Tested on Windows 11 with an RX 7900 XT, an Intel HD Graphics 520, and on a Steam Deck
  (SteamOS through Proton, on an earlier release).
