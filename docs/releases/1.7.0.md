# WWE All Stars Recomp 1.7.0

**You need your own copy of the game: a disc image of WWE All Stars (Xbox 360,
USA/Europe) and its Title Update 2, both dumped from your own console. This download
contains no game files, no update and no DLC.**

## What's new

- **Keyboard play.** The keyboard now plays as player 1's controller out of the box,
  alongside any pad, while the game window has focus. The default layout is built for
  wrestling: W A S D to move, J / K for the quick strike and grab, U / I for the strong
  ones, L / ; for the counters, Space to run, and Enter or Tab for Start. The README's
  Keyboard section has the full table. Turn it off with **Keyboard** on the CONTROLS tab.
  The launcher's new **Keys** button next to it changes any key: click an input, press its
  new key, and **+** adds a second one. The keys sit by position, so on AZERTY or QWERTZ
  they are the keys in the same place.
- **Music after Restart Match.** A match restarted from the pause menu while its music was
  playing had no music at all, and every second restart had music again. The game's music
  script unloaded the new match's track by mistake. The Xbox 360 game has the same bug;
  the port fixes it, so every match now has its music.
- **Shorter loading screens is on by default.** It cuts about 10 seconds of fixed waits
  before every match (the tips screen passes too quickly to read) and does nothing in
  online matches. If you turned it off before, it stays off. Skip startup logos is still
  off by default.
- **Help for GPU crashes.** If the game crashes on its first frames on the Native
  renderer, a new debug setting finds the draw that crashes. Add the line
  `wwe_native_debug_fault_finder = true` to `userdata\wweallstars.settings.toml`, start the
  game once, and attach the crash report from `logs\` to your GitHub issue. The game
  starts much slower with it on, so remove the line afterwards.
- `logs\runtime.log` now starts with the version and build, which makes bug reports
  easier to match to a release.

## Update

Extract the zip over your existing folder, or let the launcher's update check take you
to this page. Your settings, saves, mods and game files stay where they are.

## Known limits

- Online play pairs only players on the same release: update together with your
  friends.
- Mods are experimental. The format may still change.
- Ranked Match doesn't work yet; Player Match does.
- The in-game store button does nothing; add DLC from the launcher.
- Tested on Windows 11 with an RX 7900 XT, and on a Steam Deck (SteamOS through Proton).
