# ADR-0001: Scope: enhanced port

Status: accepted (2026-10-02); the texture-pack part is superseded by ADR-0028

## Context

v1.0 needs more than Xenia already offers, but a modding platform would delay release.

## Decision

v1.0 is an enhanced port: original behaviour plus resolution scaling, MSAA/AA and modern settings. Mod hooks are designed in but ship after v1.0. Ultrawide and HD texture packs are out.

## Consequences

Changes that would block mods later get reviewed, even though mod work itself is deferred.
